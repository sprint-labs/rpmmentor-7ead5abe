# RPM Mentor Hub

Build a premium football operations platform for RPM (Refuel Performance Management), focused on goalkeeper development, mentor management and scouting operations.

This is an internal staff platform used by mentors, scouts, analysts and management.

Design Style:

Modern, professional football intelligence platform.

Dark theme.

Premium dashboard aesthetic.

Clean typography.

Minimal but data rich.

Think Hudl, StatsBomb, Linear and Notion combined.

Core Modules:

1. Dashboard

- Total goalkeepers

- Upcoming interactions

- Overdue interactions

- Reports submitted this week

- Active mentors

- Recent activity feed

- Alerts requiring attention

2. Goalkeeper Management

- Goalkeeper profiles

- Tier assignment (Tier 1, Tier 2, Tier 3)

- Assigned mentor

- Club

- Age

- Nationality

- Contract status

- Last interaction date

- Next scheduled interaction

- Player timeline showing all activity

3. Mentor Portal

- Mentor profiles

- Assigned goalkeepers

- Upcoming tasks

- Interaction targets

- Completed observations

- Performance metrics

4. Interaction Tracking

Allow mentors to log:

- Live match attendance

- Training observation

- Face to face meeting

- Video review session

- Phone call

- WhatsApp support

- Other interaction

Each interaction should include:

- Date

- Notes

- Outcome

- Follow up actions

5. Report Submission Centre

Allow mentors and scouts to submit:

- Goalkeeper development reports

- Match reports

- Training reports

- Opposition goalkeeper reports

- Recruitment reports

Include structured scoring forms and written observations.

6. Goalkeeper Intelligence Database

Searchable database of all scouted goalkeepers.

Include:

- Rating

- Potential score

- Recommendation status

- Scouting history

- Video links

- Reports

- Nationality

- Club

- League

7. Media Library

Upload and organise:

- Video clips

- PDFs

- Images

- Voice notes

Link media to individual goalkeeper profiles.

8. Alerts Engine

Show:

- Players overdue for observation

- Players overdue for mentor contact

- Missing reports

- Upcoming matches

- Expiring action items

9. Calendar View

Monthly and weekly planner showing:

- Matches

- Planned observations

- Mentor visits

- Meetings

- Follow ups

10. Executive Dashboard

Designed for directors.

Show:

- Goalkeeper coverage

- Mentor activity

- Scouting activity

- Report volume

- Tier distribution

- Recruitment pipeline

Use realistic football data throughout.

Generate 25 sample goalkeepers, 10 mentors and 200 example reports to make the platform feel fully operational.

Focus on usability, workflows and information architecture rather than flashy marketing visuals.
